JavaScript Study Material

A structured collection of JavaScript programs covering fundamentals, control flow, loops, arrays, objects, and logic-building challenges.
This repository is designed for step-by-step learning and practice.

        Operators

        Ternary operator
        switch case
      
    3️⃣ Loops
        for loop
        while loop
        do–while loop
        for...in
        for...of
        break & continue
    
    4️⃣ Arrays & Functions Practice

🚀 How to Run
Make sure Node.js is installed.
Run any file using:
node filename.js

Example:
node 01_consolelog.js
