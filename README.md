# 🚀 JavaScript Full Learning Repository

A structured and practical JavaScript learning repository covering:

- Browser Storage
- Node.js Fundamentals
- AngularJS Basics
- Security Concepts
- Performance Optimization
- API Handling
- TypeScript Introduction
- Testing & Build Tools

This repository is designed for:

- 📘 Structured learning
- 💼 Interview preparation
- 🛠 Practical development reference
- 🧠 Concept clarity with examples
